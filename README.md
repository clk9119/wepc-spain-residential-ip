### 它的 IP 标注是“原生 IP”，不是“原生住宅 IP”

这张表里 WePC 对不同节点的 IP 用了不同标签：英国住宅、美国住宅、新加坡住宅、韩国住宅、马来西亚标的是“住宅”或“家宽”，西班牙标的是“原生 IP”。两类不是一回事。

原生 IP 指 IP 归属地和机房物理位置一致，平台查出来是西班牙，人也在西班牙。住宅 IP 指这条 IP 挂在真实家庭宽带的运营商名下，风控系统看到的更像一个普通用户家里的网络。做普通账号运营、访问本地服务，原生 IP 够用；做对住宅属性敏感的平台，两者被识别的概率有差别。

这里有个信息不一致需要你自己去确认。有第三方测评引用官方描述，称这条西班牙线是“native residential IP”（原生住宅），并给出了机房在西班牙穆尔西亚 Cartagena、上游运营商为 Aire Networks 的测试信息；但套餐表里的标注只有“原生 IP”。两种说法没能在官网产品页上交叉验证。下单前找客服书面确认这条 IP 的运营商归属和住宅属性，比事后发现不对再退要省事得多。
